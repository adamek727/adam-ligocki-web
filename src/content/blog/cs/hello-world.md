Tohle je první příspěvek na novém webu. Plánuju psát o věcech, kterými se
zabývám — programování, AI/ML, robotika — a občas i o něčem jiném.

## Co můžeš čekat

- Krátké poznámky k nástrojům a technikám.
- Delší shrnutí projektů.
- Občasné názorové texty.

```python
# Bloky kódu mají zvýrazňování syntaxe rovnou v základu.
def pozdrav(jmeno: str) -> str:
    return f"ahoj, {jmeno}"

print(pozdrav("světe"))
```
